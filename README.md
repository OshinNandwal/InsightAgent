# InsightAgent

### AI-Powered Business Intelligence Agent with GenAI, RAG & Data Analytics

InsightAgent is an AI-powered business intelligence application that allows users to ask natural-language questions about business data and receive data-driven insights.

---

## 🚀 Features

- Natural-language business question answering
- Agentic tool selection
- Automated business analytics using Pandas
- Retrieval-Augmented Generation (RAG)
- GenAI-powered business interpretation
- Automatic data visualization
- CSV and Excel dataset support

---
